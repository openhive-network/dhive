    Operation in the block_api format, e.g. {type: 'vote_operation', value: {voter, author, permlink, weight}}. Narrow on type to get the value shape of a specific operation.

    Value shapes reuse the condenser operation interfaces, with NAI assets in place of asset strings. Where those interfaces are loose they stay loose here: the pow and pow2 work and props, and extensions fields other than comment_options', are any. custom and custom_binary data is a hex string. An operation added to the chain after this list was written arrives with a type not listed here.
